# Sawaari - Ride app (React Native + Expo)
## Run
npm install && npx expo start   (phone par Expo Go se QR scan karo)
## Features
Bike/EV Bike/Bike Pool/Auto/Cab/Parcel, fare estimate, driver bids (negotiate price), women-only drivers,
scheduled rides, free cancel + free wait, SOS + trusted contacts + live trip share + OTP, wallet/UPI/cash,
reward points & streaks, Hindi/English.
## Next (real production)
Node/Firebase backend, Google Maps (react-native-maps), Razorpay, driver app, push notifications.
